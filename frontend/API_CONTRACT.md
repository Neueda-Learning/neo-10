# Card portfolio dashboard API contract

The React components use the methods in `src/api.js`. By default the application
runs a browser-only demo gateway. Set `VITE_DATA_MODE=api` to use the endpoints
below when the backend is ready.

## Data model exposed to the frontend

```json
{
  "id": 42,
  "status": "COMPLETED",
  "cardType": "PREMIUM_CARD",
  "appliedDate": "2026-01-08"
}
```

`id` is generated by `raw_data`; uploaded CSV files must contain only
`status`, `card_type` and `applied_date`.

## Upload CSV files

`POST /api/v1/raw-data/upload`

Request: `multipart/form-data`, with one or more parts named `files`.

Each CSV needs the header:

```csv
status,card_type,applied_date
```

Valid values:

```text
status: COMPLETED | REJECTED | IN_PROGRESS
card_type: PREMIUM_CARD | PLATINUM_CARD
applied_date: YYYY-MM-DD
```

Response:

```json
{
  "status": "SUCCESS",
  "rowsInserted": 20,
  "results": [
    { "filename": "customer_data_2026_01.csv", "result": "PROCESSED", "rowsInserted": 20 }
  ]
}
```

## Read raw data

`GET /api/v1/raw-data?from=2026-01-01&to=2026-12-31&cardType=ALL&page=0&size=50`

`cardType` is `ALL`, `PREMIUM_CARD` or `PLATINUM_CARD`. The date range and card
type are the only front-end filters.

```json
{
  "total": 20,
  "items": [
    { "id": 42, "status": "COMPLETED", "cardType": "PREMIUM_CARD", "appliedDate": "2026-01-08" }
  ]
}
```
